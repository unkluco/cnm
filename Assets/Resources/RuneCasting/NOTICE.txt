Modified by the Light Souls project: fine-tuned with rank-4 LoRA and cosine
triplet loss for single-stroke rune recognition, merged into the backbone,
exported to ONNX with a static 224x224 input and 192-dimensional CLS output.
The exported model is not an official Meta DINOv2 Tiny model.

RuneModelInfo.json records the source and exported artifact SHA-256 checksums.
RuneReferences.bytes contains normalized 192-dimensional reference vectors;
the original drawing dataset is not distributed.
